# FeedLink Pro

B2B Cattle Feed Ordering App UI/UX Prompt

Design a modern, premium, and highly user-friendly mobile application for a B2B Cattle Feed Ordering Platform. The application is intended for dealers, retailers, and distributors who place feed orders frequently. The primary goal is to allow users to complete an order quickly with minimal effort while maintaining a polished, professional appearance.

Overall Design Direction

Create a UI that feels like a premium business application rather than a traditional ERP system. Take inspiration from the simplicity and usability of apps such as Blinkit, Zepto, Shopify, and modern Material 3 applications. Every screen should feel clean, spacious, and intuitive.

The design should communicate trust, reliability, and efficiency.

Design Style

Minimize the number of taps required to complete common tasks.
